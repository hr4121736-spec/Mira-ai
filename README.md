# MIRA AI — CapCut ایڈیٹنگ ایجنٹ (Android APK)

MIRA آپ کے فون کی اسکرین دیکھتی ہے (Accessibility Service)، Gemini (Google AI Studio کی مفت Key) سے سوچتی ہے، اور CapCut میں خود ٹیپ / سوائپ / زوم کرتی ہے۔

## کیسے کام کرتی ہے
1. سروس آن ہوتے ہی تیرتی چیٹ کھلتی ہے اور پوچھتی ہے: "آج کون سی ویڈیو بنانی ہے؟"
2. آپ بتاتے ہیں: اسٹائل، دورانیہ، کس سیکنڈ پر کٹ، میوزک وغیرہ۔
3. MIRA "گہری سوچ" والا پلان بناتی ہے (سیکنڈ بہ سیکنڈ) اور اس میں اپنی طرف سے مفید اضافے بھی جوڑتی ہے (Stabilize، کلر گریڈ، Shake/Flash، آڈیو Fade)۔
4. پھر خود CapCut میں کٹس، رفتار، ایفیکٹس، ٹرانزیشنز، کی فریمز لگاتی ہے اور ہر قدم پر نئی اسکرین دیکھ کر تصدیق کرتی ہے۔
5. Save / Export سے پہلے آپ سے ہاں/نہیں پوچھتی۔ یہ لاک کوڈ میں بھی ہے: Save/Export/Share والے بٹن اجازت کے بغیر ٹیپ ہی نہیں ہوتے۔

## APK بنانے کا طریقہ (مفت، GitHub Actions)
1. github.com پر مفت اکاؤنٹ بنائیں اور نئی Private repository بنائیں۔
2. اس ZIP کو کھولیں اور اندر کی تمام فائلیں اور فولڈرز (چھپا ہوا `.github` فولڈر بھی) repository میں Upload کریں۔ کمپیوٹر کے براؤزر میں "Add file ➜ Upload files" فولڈرز سمیت قبول کرتا ہے۔
3. اوپر Actions ٹیب ➜ "Build APK" ➜ Run workflow (یا خودبخود چل جائے گا)۔ تقریباً 5 منٹ لگتے ہیں۔
4. ختم ہونے پر اسی صفحے کے نیچے Artifacts میں `MIRA-AI-apk` ڈاؤن لوڈ کریں، کھولیں، اندر `app-debug.apk` فون پر انسٹال کریں۔
5. اگر بلڈ ناکام ہو تو لال ✗ والے مرحلے کی آخری 30 لائنیں کاپی کر کے مجھے بھیج دیں، میں ٹھیک کر دوں گا۔

## Gemini Key (مفت)
aistudio.google.com/apikey سے Key بنائیں۔ مفت پلان کی روزانہ اور فی منٹ حدیں ہیں؛ حد پوری ہو تو MIRA خود انتظار کر کے دوبارہ کوشش کرتی ہے۔

## فون پر سیٹ اپ
1. MIRA AI کھولیں ➜ Key paste ➜ "محفوظ کریں" ➜ "Key ٹیسٹ کریں" (✅ آنا چاہیے)۔
2. اینڈرائیڈ 13 یا اس سے اوپر: Settings ➜ Apps ➜ MIRA AI ➜ ⋮ ➜ **Allow restricted settings**۔
3. Settings ➜ Accessibility ➜ MIRA AI ➜ آن۔
4. Settings ➜ Apps ➜ MIRA AI ➜ Battery ➜ **Unrestricted** (ورنہ بیک گراؤنڈ میں بند ہو سکتی ہے)۔
5. CapCut کھولیں، سبز "M" بٹن (کھینچ کر ہلا سکتے ہیں) دبا کر چیٹ کھولیں۔

## ماڈلز
- عام کام: `gemini-2.5-flash` (ڈیفالٹ)۔ حد جلد پوری ہو تو `gemini-2.5-flash-lite` آزمائیں۔
- پلان کے لیے مضبوط ماڈل چاہیں تو ایپ میں `gemini-2.5-pro` لکھیں (مفت حد کم ہوتی ہے)۔

## سچ بات: حدود
- ایک 10 سیکنڈ کی ایڈیٹ میں درجنوں قدم لگتے ہیں اور ہر قدم ایک Gemini کال ہے، اس لیے مفت Key پر یہ منٹوں میں نہیں بلکہ کئی منٹ سے زیادہ لے سکتا ہے۔
- CapCut کا ڈیزائن ورژن کے ساتھ بدلتا ہے۔ MIRA ہر بار اسکرین دیکھتی ہے، پھر بھی کبھی غلط بٹن دبا سکتی ہے۔ ایسا ہو تو چیٹ میں بتائیں یا ⏹ دبائیں۔
- "ہر قدم پر نیا اسکرین شاٹ" کی وجہ سے MIRA آپ کی اسکرین کا مواد Google کو بھیجتی ہے۔ حساس ایپس CapCut کے علاوہ کھلی ہوں تو MIRA بند رکھیں۔
- API Key فون میں ایپ کی نجی اسٹوریج میں رہتی ہے، کہیں اور نہیں بھیجی جاتی۔
- اسکرین شاٹ اور جیسچر کے لیے Android 11 یا اوپر ضروری ہے۔
- یہ پہلا ورژن ہے۔ اگر کسی فون پر کوئی بٹن یا سیکشن ٹھیک نہ چلے تو مجھے بتائیں؛ پرامپٹ اور کوڈ دونوں میں بہتری آسان ہے۔
